# Créditos dos sons naturais (aba Meditação)

Todos os áudios vêm do Wikimedia Commons. Os arquivos deste projeto são trechos
editados dos originais: recorte de 56 a 92 segundos, emenda com crossfade para tocar
em loop, nivelamento de volume e conversão para MP3 (128 kbps).
